# 데이터

기존 LAYA 생성 데이터는 [generated/laya](generated/laya/)에 실제 이동했다. 이전 결과 폴더에서의 접근도 유지한다.

공식 LAYA 40/20 학습·개발 데이터와 원본 100개 평가 스냅샷은 진행 중인 작업과 원본 코드 경로를 보존하기 위해 아직 기존 위치에 있다. [데이터 출처 안내](manifests/README.md)를 따른다.

학습 데이터·평가 데이터는 실행 로그와 분리한다. 새 데이터는 출처·seed·분할·중복 감사·해시를 함께 기록한다. 이 디렉터리 재구성 과정에서 새 데이터를 생성하지 않았다.
