# LAYA 실제 공개 관측의 표·문장 비교

2026-10-10에 사전 계획을 고정하고 수행한 시뮬레이터 관측 실험이다. 공개 도구로 수집한 실제 장애 증거를 사용했으며, 정답에서 만든 합성 신호가 아니다. 실장비 네트워크 진단 성능이나 LAYA 도구 탐색 성능을 측정한 것은 아니다.

## 실행과 데이터

- 완료: 관측96개 생성, 표/문장 동등성 검증, 6개 모델 학습(각1024 optimizer updates), 기본 모델2표현 및 학습 모델6개의 학습/새 평가, 선택지 순서 검사, 6개 가중치 복원 검증.
- 미실행: 전체 Encoder 미세조정, 새 LAYA 도구 탐색 rollout, 유료 GPT/Jev API, 정상/복합 장애·외부 토폴로지·실장비 평가.
- 중단: 문장 seed63의 첫 실행은 세션 중단 뒤 프로세스가 사라졌고 완료 가중치가 없었다. 원래 폴더를 prose_63_interrupted_attempt1로 보존하고 같은 설정·기본 checkpoint에서 재시작했다. 완료된5개 실행은 재학습하지 않았다. 중단 실행의 정확한 갱신 수·시간은 복구할 수 없으며 아래 시간 합계에 포함되지 않는다.
- Star/Linear 각4노드×4유형에서 학습4개/평가8개씩: 학습32·평가64. 학습91000000대, 평가92000000대의 별도 episode seed. 유형마다 평가16개다.
- 후보96개, 채택96개, 중복/제외0개. 기존 결과383파일·저장 compact 관측11378건과 seed 및 기록 가능한 관측을 검사했다. 기존 전체 LAYA 데이터2112에피소드의 모든 단계도 검사했다. 관측 원문이 없는 기록은 seed만 검사할 수 있었다.
- 학습/평가 관측의 완전일치와 step_fraction 제외 핵심일치 모두0건. 다만 지연 연속값과 step_fraction을 제거하면 새 평가47/64개가 학습과 같은 구조적 관측 패턴이다. 새로운 물리 에피소드이며, 새로운 장애 패턴/토폴로지 일반화로 부르지 않는다.
- scan → 모든 장치 status → 모든 장치 interfaces → 모든 명목 방향 링크 ping의 고정 순서로 수집했다. 정답을 보고 도구를 선택하거나 종료하지 않았다. 각 사례의 실제 도구 결과와 전체 공개 그래프 필드를 candidates.jsonl에 보존했다.
- 전문가 성공: 학습32/32, 평가64/64. 전문가 성공으로 선별하지 않았다. 전문가 판단은 raw memory를 이용하므로 압축 그래프만으로 동일한 성능이 보장되는 것은 아니다.
- 표와 영문 문장은 같은 GraphObs 전체 필드·ID·순서·5자리 유효숫자 값을 전달한다. 양방향 파서로192개 표현의 필드/값 일치를 확인했다. 정답·전문가 결론·사례ID는 입력에 없다. 원시 도구 정보 전체와 GraphObs가 동등하다는 주장은 아니다.
- 최종6개 가중치와 해시를 모두 저장한 뒤 새 평가를 개방했다. 중간 점수로 조건을 고르거나 재학습하지 않았다.

## 조건과 사전 기준

기본 checkpoint revision 7b928d828b7b0e022f929d9bd2e44165aa270148, FP32, 마지막 Encoder 블록+Head만 학습했다. Encoder/Head LR=2.5e-5/1e-4, AdamW soft-CE, microbatch1/accumulation1, 선택지 섞기, seed41/52/63이다. 32사례×2질문×16epochs=1024 실제 optimizer.step 호출을 계수했다. 유형·위치 각각512회이므로 기존 유형 전용1024회 실험과 유형 학습 노출량은 다르다. cosine schedule은1024회에 맞췄다.

암기 통과는 학습 유형·Exact 모두95%. 새 사례 통과는 유형 정확도·macro-F1·위치·Exact 모두95%이고, 유형24순서 및 위치3순서의 Exact도 모두95% 이상이다. 최종 checkpoint를 사용했다. 기준 미달은 모델 고유 능력의 불가능성 판정이 아니다.

## 표현 비교와 판정

- table: 암기 기준 0/3, 새 사례 기준 0/3. 새 유형 평균 25.00%, Exact 평균 7.81%.
- prose: 암기 기준 0/3, 새 사례 기준 0/3. 새 유형 평균 36.98%, Exact 평균 10.94%.
- 문장−표 type_accuracy: +11.98%p, 사례 bootstrap95% 구간 [+0.52, +23.44]%p.
- 문장−표 location_accuracy: +0.52%p, 사례 bootstrap95% 구간 [-12.50, +13.02]%p.
- 문장−표 exact: +3.12%p, 사례 bootstrap95% 구간 [-5.73, +11.46]%p.
- 문장−표 macro_f1: +13.72%p, 사례 bootstrap95% 구간 [+5.36, +20.85]%p.

구간은 같은64개 사례에서 세 seed의 차이를 평균한 뒤 사례를 재표집했다. seed 모집단의 불확실성이나 다중 비교 보정은 포함하지 않는다. 표현은 정보량을 맞췄지만 토큰 수·문장 구조·계산량은 다르므로 순수한 자연어 의미 효과만 분리한 실험은 아니다.

- “이 고정 예산·표현·부분 학습으로 새 관측에서 안정적인95% 판단을 확보한다”는 사전 가설은 통과하지 못했다. 충분한 공개 관측을 수집해도 이번 판단 구성에서 실패가 남으므로, 이번 실패를 탐색 단계만으로 설명할 수 없다.
- 학습 사례 암기 기준도 모두 미달했다. 따라서 새로운 사례에서의 낮은 점수를 일반화 문제 하나로 해석할 수 없다. 최적화·노출 예산·표현 적응 문제는 아직 분리되지 않았다.
- table의 기본 모델 대비 새 Exact 평균 변화는 +0.00%p다. 손실 변화와 별개로 실제 판단 점수의 개선량을 보고한다.
- prose의 기본 모델 대비 새 Exact 평균 변화는 -1.56%p다. 손실 변화와 별개로 실제 판단 점수의 개선량을 보고한다.
- 문장−표 Exact 차이 구간이0을 포함한다. 이 표본으로 문장 표현의 우위를 확정할 수 없으며, 두 표현이 동등하다고 입증한 것도 아니다.
- 관측 원문을 이용한 전문가 성공은 이 시뮬레이터 사례에 진단 가능한 공개 증거가 있음을 지지한다. 그 정보가 현재 그래프 압축·표현에서 충분히 보존되고 LAYA가 활용할 수 있는지는 별도 문제다. 모델 자체의 능력 상한이나 전체 Encoder 학습의 효과는 이번 결과로 기각할 수 없다.

매 canonical 평가에서 유형·node·edge 세 질문을 계산해 oracle 보조 결과도 확보했다. 시간은 실제 운영시 두 질문만 계산하는 지연이 아니다. GPU peak는 PyTorch 할당량이며 nvidia-smi의 전체 장치 메모리·사용률 시계열도 JSON에 보존했다. 장치 메모리에는 디스플레이 등 다른 프로세스가 포함될 수 있다. API 비용0, 전력 비용 미측정.

모든 입력은4096/1024 예산에서 공식 tokenizer로 잘림·후보 누락/병합을 검사했다. 저장 가중치에는 마지막 Encoder 블록과 Head가 포함된다. 기본 모델에 다시 로드한6개 실행의 canonical logits 최대오차는 0.0이며 예측·점수가 일치했다.

새 평가 개방 전 실행 보완안에 따라 순서 반복 추론만 batch4로 묶었다. 학습 사례에서 두 표현·세 질문의 순서별 단일/배치 추론을 비교하고, 평가에서도 모델별192개 canonical 비교에서 logits 오차<1e-4와 예측 일치를 확인했다. canonical 추론은 단일 실행이다. 학습·데이터·판정 기준은 변경하지 않았다.
