# GPT-6.1 Sol / Jev 예비 실험 결과

2026-10-09. **64개 독립 장애 사례 × 두 모델 = 128회 예비 평가를 완료했다.**
이는 원래 이름 조건의 개발용 pilot이며, 계획한 9,600회 본 평가·이름 변경·3회 반복은 아직 실행하지 않았다.

## 어떻게 장애를 찾게 했나

두 모델에 같은 지시를 보냈다. 아래는 실제 영어 프롬프트의 한국어 설명이다.

> 네트워크 장애 하나의 유형과 위치를 찾아라. 지금 관측한 정보만 사용하라.
> 장비 목록과 명목 연결 구조를 안다고 해서 실제 상태까지 아는 것은 아니다.
> 필요하면 도구로 증거를 모은 뒤 진단하라. 불필요한 반복을 줄여라.
> 주어진 후보 중 다음 행동 하나를 선택하라.

여기에 숫자 특징을 포함한 공개 그래프 JSON과 완전한 행동 후보 목록을 붙였다.
예: 장비 A의 상태 확인, A의 인터페이스 확인, A→B ping, A의 장비 고장 진단, A–B의 링크 장애 진단.
도구를 실행할 때마다 결과가 반영된 관측표를 다시 보내고 다음 행동을 골랐다. 최대 40번 선택했다.
정답·숨은 상태·Rule 추천은 전달하지 않았으며, 이전 대화 전체 대신 관측 결과를 누적한 현재 표를 사용했다.
GPT는 행동 ID JSON, Jev는 동일 후보에서 Choice를 반환한다. Jev-ultrafast의 브라우저 실행은 사용하지 않았다.

이 입력은 사람에게 익숙한 원시 로그 문장이 아니라 기존 GNN 실험과 연결하기 위한 특징 표다.
따라서 결과는 **현재 표 표현과 공통 프롬프트에 대한 비교**다. 모델마다 최적화한 최고 성능 비교가 아니다.
실제 영어 지시는 [고정 프롬프트](../../../../netheal-topology-generalization/results/api_pilot_20261009/instructions.txt),
요청 JSON은 해당 실행 폴더의 requests.jsonl에 보존했다.

## 관측된 차이

| 지표 | GPT-6.1 Sol (medium) | Jev 1.13.0 |
|---|---:|---:|
| Exact: 유형·위치 모두 정답 | **56/64, 87.5%** | **17/64, 26.6%** |
| 오진 | 8/64, 12.5% | 43/64, 67.2% |
| 40단계 내 미완료 | 0/64 | 4/64, 6.3% |
| 평균 전체 진단 시간 | 21.07초 | 1.36초 |
| p95 전체 진단 시간 | 43.07초 | 8.82초 |
| 평균 에피소드 비용 | $0.048026 | $0.001562 |
| 64회 총비용 | $3.073663 | $0.099938 |
| 총비용 / 정답 수 | $0.054887 | $0.005879 |
| 평균 도구 호출 | 5.45 | 4.84 |
| 반복 도구 호출 비율 | 2.3% | 69.7% |
| 전체 API 요청 | 413 | 370 |

비용은 **API usage × 기록한 단가의 추정액**이며 청구서와 대조한 확정액이 아니다.
위 비용 합계는 pilot 약 **$3.17**다. 별도 연결 점검·smoke 약 $0.037을 포함하면 약 **$3.21**다.
수집된 요청에서 사용량 누락이나 API 오류는 없었다. 지연은 클라이언트 왕복과 도구 실행 등을 포함한 실측이다.

GPT가 이 조건에서 더 정확했고 Jev는 더 빠르고 저렴했다.
정답당 비용도 Jev가 낮지만, 높은 오진율과 동시에 해석해야 한다. 오진으로 인한 운영 피해 비용은 측정하지 않았다.
Jev의 평균 도구 호출이 적어도 반복 비율이 높은 것은 일부 사례가 같은 도구를 반복하다 종료했기 때문이다.

장애 유형별 Exact(각 16사례):

| 장애 | GPT | Jev |
|---|---:|---:|
| 장비 고장 | 100% | 6.3% |
| 성능 저하 | 100% | 0% |
| 설정 오류 | 100% | 0% |
| 링크 장애 | 50% | 100% |

GPT의 오진 8건은 링크 장애를 설정 오류로 분류한 경우였다.
Jev는 링크 장애를 잘 맞혔으나 다른 장애 구분과 위치 선택에서 실패했다.
표현 방식이나 질문 분해가 원인인지는 아직 검증하지 않았으므로 “Jev 자체가 네트워크 진단에 불가능하다”는 결론을 내릴 수 없다.

짝지은 조건별 bootstrap의 탐색적 98.33% 구간에서 GPT−Jev Exact 차이는 +60.9%p [39.1, 79.7],
평균 시간 차이는 +19.71초 [15.93, 25.10], 평균 비용 차이는 +$0.04646 [$0.03813, $0.05599]였다.
표본은 개발용 64개이며 반복·이름 변경 효과를 포함하지 않는다.

## 검증과 다음 단계

소스·설정·프롬프트 해시, 128회 예정표 완전성, 64개 사례의 공통 정답, Exact 재계산 및 비용 합계 검증을 통과했다.
관련 테스트는 기존 회귀 검사를 포함해 **16개 통과**했다.

본 평가 전에 특징 값의 의미 설명을 충분히 제공했는지와 공통 상태 표현의 적합성을 점검할 필요가 있다.
특징 표를 읽기 쉬운 장비별 문장/객체로 바꾸는 비교, Jev의 질문 분해 비교는 **별도 개발 ablation**으로 구분해야 한다.
이 pilot 결과를 보고 수정했다면 같은 사례의 개선을 최종 성능으로 보고하지 않고, 설계를 다시 고정한 뒤 새 본 평가 사례를 사용한다.
정상 오경보·복합 장애·증거 개입·실장비·복구 성능은 여전히 미검증이다.
