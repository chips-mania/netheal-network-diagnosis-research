# 포트폴리오 공개 범위

2026-10-14 기준으로 연구 코드, 실행 설정, 논문 및 결과 보고서, 그래프, 요약 JSON·CSV, 검증 결과와 공개 평가 스냅샷을 Git에 포함한다.

핵심 비교 문서는 [Claude–JEV 논문 초안](research/official_benchmark/reports/claude_jev_comparison_paper_20261014.md)이다. 같은 초기 사례 100개에서 구조화 상태 JEV는 48/100, 공개 Claude는 66/100을 기록했다. JEV 입력/API 오류는 0건이며 실제 요청 1,946건의 관측 일치 검증을 통과했다. 입력 형식과 실행 환경의 차이는 논문에 명시했다.

## 로컬에서만 보존하는 산출물

- 모델·optimizer 가중치와 학습 체크포인트
- 생성 학습 데이터와 tokenizer 복사본
- 원본 API 요청·응답, 도구 실행 이력 및 학습 로그
- 이미지·소스 다운로드 압축 파일과 임시 실행 archive
- 전체 입력 전문을 반복 전개한 대용량 사례 문서
- API 키, `.env`, 가상환경 및 머신별 설정

이 파일들은 `.gitignore`로 신규 추적에서 제외한다. 로컬 원본을 삭제하지 않으며, 기존에 추적된 소형 파일은 유지한다. 보고서에서 원본 로그 보존을 언급하는 것은 연구 수행 환경에서의 보존을 의미한다. 공개 브랜치에는 원본 로그 전체가 포함되지 않으므로, 클론만으로 원본 요청의 사후 감사를 모두 재실행할 수는 없다. 반면 요약 결과, 감사 결과 및 감사 구현은 확인할 수 있다. 과거 임시 산출물을 참조하는 일부 문서 링크도 로컬 자료를 전제로 한다.

## 실행과 재현

환경 및 의존성 설치 방법은 [루트 README](../README.md)와 실험별 실행 문서를 따른다. 기존 공개 스냅샷을 이용해 새 실험을 수행할 수 있으며, API 실험에는 별도의 사용자 키와 비용이 필요하다. 제외된 학습 가중치나 데이터가 필요한 실험은 해당 산출물을 먼저 생성해야 한다.

원본 로그와 가중치의 공개 배포가 필요한 경우에는 별도 데이터 저장소나 Git LFS 사용 여부를 검토한다. 이번 브랜치는 결과를 검토하기 위한 포트폴리오이며 대용량 원자료 전체의 배포를 포함하지 않는다.
