# LAYA 입력 실행 보완 — 2026-10-12 KST

학습은 아직 시작하지 않았다. 데이터 생성에서 원본 hierarchical 토폴로지 생성기가 요청한 장비 수와 다른 실제 장비 수를 반환하는 사례를 확인했다. 원본 생성 코드를 수정하거나 사례를 선별하지 않는다. 데이터의 n은 요청값으로 보존하고, 모델 입력의 network_size는 실제 공개 도구 응답 info.network_size에서 읽는다. 요청 수와 실제 수를 데이터 감사에 함께 보고한다.

긴 상태의 입력 분할은 Jev v4처럼 시간 순서의 이력 묶음을 먼저 시도한다. 각 묶음에 최신 공개 결과를 반복하므로 현재 전역 관측을 함께 읽을 수 있다. LAYA tokenizer의 4096/1024 한도를 만족하지 못하는 단일 묶음은 JSON 경로/값 분할로 처리한다. 시간 분할은 사건 수, 트리 분할은 원자료 값의 바이트 수로 확률을 가중 평균한다. 모든 원자료와 시간 순서의 복원을 검사한다. 학습 시에는 고정 RNG로 묶음 하나를 선택한다는 약한 감독 조건을 유지한다.

공식 평가 점수와 학습/개발 정확도는 이 변경을 결정할 때 사용하지 않았다. 최종 입력 코드·학습 코드를 학습 시작 전에 해시로 고정한다. 자원 점검 가중치는 본 학습에 사용하지 않는다.
