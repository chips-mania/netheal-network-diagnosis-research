# 평가 실행 보완 — 점수 확인 전

2026-10-10, 6개 모델 학습이 진행 중이고 새 평가를 열기 전 작성했다.

선택지 순서 반복 추론만 batch size4로 묶는다. 학습의 microbatch1,1024 updates와 모든 데이터·질문·판정 기준은 변경하지 않는다. canonical 유형/node/edge 질문은 기존처럼 각각 단일 추론하고 평가 분기는 예측 유형으로 정한다.

`laya_observation_batched_eval.py conformance`를 모든 학습 완료 후 학습 사례만 사용해 실행한다. 두 표현의 학습 첫 사례에서 유형24순서와 위치3순서의 단일/배치 logits 오차<1e-4 및 의미상 예측 일치를 확인해야 평가를 열 수 있다. 새 평가에서도 매 사례·질문의 배치 canonical 결과와 기존 단일 결과를 비교해 같은 조건을 확인한다. 판정 실패 시 중단하며 모델/데이터 조건을 새 평가 점수에 맞춰 바꾸지 않는다.

이는 반복 평가의 계산 방식 보완이다. 학습량·모델 선택·새 평가 사례·통과 기준 변경이나 추가 모델 실험이 아니다. 원래 실행 소스 스냅샷은 보존한다. 추가 스크립트와 이 문서도 평가 개방 전 해시를 기록한다.
