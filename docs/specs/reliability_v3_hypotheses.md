# 후속 실험 v3: 순위 의존성과 학습 토폴로지 다양성

상태: 아래 설계를 본 실험 학습/평가 전에 고정한다. LAYA, Jev 및 일반 LLM 호출은 제외한다.
이 실험은 v2에서 발견한 현상에 근거한 전향적 후속 시험이며, 독립 기관 사전등록은 아니다.
현재 범위는 앞선 계획의 1·2단계다. 정상 판정·관측 잡음·실네트워크 단계까지 완료했다고 주장하지 않는다.

## 연구 질문과 가설

Q: 관측 기반 GNN 진단의 구조 전이가 순위 단서 의존 완화와 학습 구조 다양화로 개선되는가?

- H1 (순위 증강): ID/순서 증강은 기존 특징 대비 재명명 평가의 Exact를 개선하고
  canonical→renamed 성능 감소를 줄인다.
- H2 (구조 다양성): 같은 총 전문가 에피소드 수에서 Star+Linear 학습은 Star-only보다
  보지 않은 Mesh/Random의 평균 Exact를 높인다.
- H3 (상호작용, 탐색적): 순위 증강의 효과가 혼합 구조 학습에서 더 크다.
- 순위 제거는 H1의 기전 대조군이다. 대칭 노드 구분/일관된 탐색 순서가 어려워질 수 있으므로
  순위 제거 자체의 성능 상승을 가정하지 않는다.

## 고정 비교군

GNN 3 × 2 요인:
- rank: original / removed / augmented.
- curriculum: star / mixed (Star 50%, Linear 50%).
- 모든 군은 같은 GNN(64 hidden, 2 message layers), BC loss, Adam lr=3e-4,
  batch 64, 6,000 optimizer updates. 진단 가중치·샘플링 multiplier 모두 1.
- 6,000 updates는 이번 후속 시험의 고정 계산 예산이다. v2의 약 14,160 updates와 다르므로
  두 실행의 숫자를 직접 개선 전후로 비교하지 않는다. 테스트를 보고 학습량을 변경하지 않는다.
- 규칙 정책은 해결 가능성의 기준선으로 모든 새 사례에서 평가한다.
- 기존 v2 GNN은 보존한다. v3 original/star를 동일 학습량의 내부 대조군으로 사용한다.
- 추가 MLP 재학습은 이번 기전 연구에 넣지 않는다. v2의 MLP 비교는 별도 기존 근거다.

## 학습 데이터와 반복

- 크기 4/5/6 × 크기별 704개 성공 데모 = 2,112개/군.
- 장애 4종 균형: 크기별 종류당 176개.
- mixed는 종류당 Star 88개 + Linear 88개. star의 첫 88개를 그대로 공유한다.
- 데이터 수집 seed와 초기화 seed를 바꾼 독립 반복 3개: replica 41/52/63.
  각 반복 안에서는 모든 군이 대응하는 공통 데이터와 같은 초기화 seed를 사용한다.
  데이터 변동과 초기화 변동을 각각 추정하는 완전 교차 설계는 아니다.
- 데모 선별 전 시도·실패·seed 및 원래 의미 행동을 기록한다.
- 성공 에피소드 수와 optimizer updates는 맞추지만 구조별 episode 길이가 달라
  transition 수는 같지 않다. 그 차이를 보고한다.

## 순위/재명명 정의

- original: 기존 ID 사전식 순위 특징을 유지.
- removed: node id_rank 및 edge src/dst_rank를 0으로 만든다.
- augmented: 데모마다 4개의 고정된 무작위 ID bijection·node/edge ordering 변형을 생성.
  node/edge 특징과 연결 인덱스, 정답 pointer를 함께 치환한다. 총 optimizer updates는 동일.
- 최종 paired stress는 각 사례에 새 무작위 별칭(ID)과 node/edge 순서를 적용한다.
  관측 숫자·연결·실제 장애는 유지하고 모델 출력만 원래 장비 ID로 되돌려 실행한다.
  같은 대응 행동에는 원래 의미 행동을 이용한 동일 RNG를 적용한다.
- 이는 모델의 전체 공개 그래프 입력에 대한 일관된 재명명이다.
  원본 시뮬레이터 장비 이름과 Rule 교사의 이름을 바꾸는 실험은 아니다.
- 증강 데모는 기존 교사의 동일 의미 행동을 유지한다. 전문가와 다른 유효한 탐색 순서가
  있을 수 있으므로 낮은 모방 loss 또는 단일-step 행동 일치율만으로 판단하지 않는다.

## 평가와 데이터 분리

- 학습 seed 영역 2,000,000 이상; 최종 평가 seed 영역 8,000,000 이상.
- 최종 조건: Star 6/10/12, Linear 6, Mesh 6/10, Random 6/10.
- 조건별 100개 새 독립 사례, 장애별 25개. canonical/renamed를 같은 사례에서 짝지어 평가.
- 정책당 8 × 100 × 2 = 1,600회. 18개 학습 모델로 28,800회 + Rule 800회.
- 공통 40-step 예산, 알려진 명목 inventory, 관측 기반 특징, 내부 장애 정보 차단 유지.
- 본 실험의 모든 모델을 학습·저장한 후 최종 평가를 연다. 중간 평가로 모델/설정 선택하지 않는다.
- 별도의 최적화/모델 선택을 하지 않으므로 이번에는 개발 세트를 만들어 선택하지 않는다.
  이후 이 결과를 이용해 방법을 고르면 반드시 추가 untouched 최종 세트가 필요하다.

## 주요 판정과 통계

H1 주요 효과: curriculum 두 조건과 전체 평가 조건을 동일 가중한
augmented−original의 renamed Exact. canonical→renamed 감소의 개선도 함께 제시.
H2 주요 효과: rank 세 조건과 Mesh6/10·Random6/10 조건을 동일 가중한 mixed−star Exact
(canonical/renamed 평균).
두 주요 효과는 replica와 짝지은 시나리오를 재표본화한 hierarchical bootstrap
97.5% 구간을 사용한다(각 양측 alpha .025로 두 가설에 대한 Bonferroni 배분).
하한 >0이면 이번 설정에서 개선 근거, 상한 <0이면 악화 근거, 0을 포함하면 불확실로 판정.
이는 효과 구간 기반 탐색 후 확인이며 3회 반복에서 구간 안정성은 제한적이다.
세부 조건별 구간은 보조 95%이며 다중 비교 보정 없이 탐색적으로 해석한다.
사례수는 계산 예산에 따른 것이며 사전 power 분석으로 정한 표본수가 아니다.

## 함께 볼 운영 지표

Exact, 유형/위치 정확도, 유형 macro F1, 오진 제출·미진단 timeout,
도구 호출·반복·상대 비용, 성공까지 단계, 단계별 성공 누적률,
CPU 결정시간 p50/p95를 기록한다.
독립 all-pairs ping(쌍당 5회)으로 도달 실패율, 성공 지연, 같은 pair 지연 변동,
카운터가 제공된 호출의 손실률/커버리지와 정상 반사실을 수집한다.
실제 throughput, packet-level jitter, MTTR은 측정하지 않는다.
정상 false alarm은 이번 single-fault 설정에서 측정 불가다.

## 보존 및 중단

기존 v2 결과/코드를 덮어쓰지 않는다. 새 폴더, protocol/spec/source/checkpoint/data hashes,
전체 에피소드 요약 및 조건별 첫 4개 상세 trace를 저장한다.
학습 완료 manifest를 쓴 다음 평가를 시작한다.
기술 오류 수정 시 원인과 수정 내용을 기록하고 영향을 받는 실행을 별도 폴더에서 다시 수행한다.
LAYA/Jev API 키, 설치, 호출, 추가 학습은 수행하지 않는다.
