# Jev 문맥 수정 최종 재측정 명세

작성일: 2026-10-11 KST. 본 평가 전에 소스·이 문서의 해시를 고정한다.

## 중단 기록 및 추가 수정

v3는 14개 에피소드의 결과를 기록한 시점에서 기술적 입력 가드 실패 때문에 중단했다. 일부 진행 중 요청도 보존한다. `0f3393c8-6cc3-4016-a758-d0b60ffed2db`의 ping 인자 선택에서는 많은 인자 후보와 공개 관측을 함께 넣을 때 24,000바이트 가드를 충족하지 못했다. API 오류를 피한 로컬 중단이며, 진단 오답을 보고 설정을 바꾼 것이 아니다. v3는 전체 완료 결과로 보고하지 않는다.

v4는 [v3 명세](netheal_official_jev_execution_v3_20261011.md)의 모델·공식 100개 사례·환경·힌트·단계·시간·동시성·채점·기본 손실 없는 압축·이력 분할·재시도 규칙을 유지한다. 다음 예외 처리를 추가한다.

- 이력 단위 분할로도 관측과 질문을 합친 크기가 가드에 들지 않으면, 원래 JSON 트리를 경로(path)와 값(value)인 부분 자료로 나눈다. 큰 객체/배열은 자식 단위로 재귀 분할한다. 각 묶음에 공개 과제·힌트·예산·현재 turn을 반복하고 동일 선택지를 묻는다.
- 모든 부분 자료를 원래 트리로 복원하여 원래 state와 정확히 같은지 검사한다. 관측/선택지 삭제, 숫자 반올림, 정답 기반 요약은 없다. 비어 있는 자료도 보존한다.
- 트리 분할의 결합 가중치는 각 묶음에 포함된 원자료 value의 compact JSON UTF-8 바이트 합이다. 선택지별 반환 확률을 가중 평균하고 최대값을 고른다. 동률은 첫 선택지다. 단일 요청은 제공사 choice를 따른다. 기존 이력 분할은 사건 수 가중 평균을 유지한다.
- 트리 경로 표현과 분할 확률 결합은 원시 관측을 한 번에 읽는 것과 다르다. 특히 증거 간 관계 추론에 불리할 수 있다. 정보 보존과 모델 이해 수준을 동일시하지 않는다.
- 단일 숫자/문자열이나 고정 질문 자체가 한도에 들어가지 않는 예외는 명시적 오류로 남긴다. 한도 때문에 증거를 버리지 않는다.

## 동결 전 확인 및 판정

v3 실패 사례의 실제 ping 인자 후보와 관측을 포함한 요청은 트리 분할 2묶음 모두 Jev HTTP 200으로 수용됐다. 개발 3 turn smoke도 요청 5회 모두 정상 응답했다. v2 기존 1,571개 요청에 대해 질문 크기를 포함한 분할 및 완전 복원을 다시 검사한다. v4 압축 코드는 v3 최종 검증 코드와 동일하다.

전체 100개를 새 디렉터리에서 다시 실행한다. 시작 전에 명세와 소스를 동결하고, 실행 도중 성능에 따라 설정을 변경하지 않는다. 문맥 관련 API/로컬 오류 건수 0개가 이 고정 평가에서의 기술 판정 기준이다. 성능은 전체 분모로 성공·오진·미완료, 유형 정확도/macro-F1, 위치 정확도, 공식 장비 수 가중 성공률을 보고한다. 기존 오류 39개와 전체 100개 결과를 구분한다. v2 및 원본 Claude와 비교하되 독립 미관측 평가나 완전히 같은 에이전트 인터페이스라고 주장하지 않는다.

비용은 중단된 v3, v4의 개발 확인 및 본 평가를 포함하여 분리 집계한다. 원시 요청·결과와 기존 v1/v2/v3 소스 사본을 덮어쓰지 않는다. 출력 폴더는 `results/netheal_official_jev_20261011_v4/`다. Sol/Claude 호출과 LAYA 학습은 미실행이다.

```powershell
.runtime/jev-official-venv/Scripts/python.exe -X utf8 netheal-topology-generalization/scripts/audit_jev_partitions_v4.py
```
